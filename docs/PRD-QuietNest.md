# QuietNest（白噪音 iOS App）产品文档 v1.0

## 1. 文档目标
基于 `docs/noise.html` 原型，定义 QuietNest 的首版产品范围、核心体验、功能规格与交付标准，指导设计、iOS 开发与测试协作。

## 2. 产品定位
- 产品类型：离线优先的白噪音与环境音混音工具（助眠/专注/放松）。
- 核心价值：用最少步骤快速获得可用音景，并允许用户做轻量个性化调音。
- 差异化主张：无广告、低打扰、支持离线、一次买断（原型显示 ¥38）+ 可选扩展音景包。

## 3. 目标用户与场景
- 助眠用户：睡前快速开启音景，设置定时后入睡。
- 专注用户：工作学习时稳定背景声，减少环境噪音干扰。
- 放松用户：通勤/休息时用自然音放松情绪。

## 4. 目标与指标（MVP）
### 4.1 业务目标
- 上线一个可独立完成“选音-播放-定时”的最小可用版本。
- 建立“官方预设 + 我的预设”的内容框架。

### 4.2 体验目标
- 从打开 App 到开始播放不超过 2 步。
- 核心操作集中在单手拇指可达区域（屏幕中下部）。

### 4.3 指标建议
- 新用户首日播放转化率（打开后 60 秒内播放）>= 70%。
- 定时功能使用率（播放会话中使用定时）>= 35%。
- 人均单次播放时长 >= 20 分钟。
- 7 日留存（D7）>= 20%（MVP 阶段观察值）。

## 5. 信息架构
- 页面 1：引导页（3 步 Onboarding）
- 页面 2：主页（混音与播放主界面）
- 页面 3：设置页
- 浮层 1：预设 Bottom Sheet
- 浮层 2：定时 Bottom Sheet

## 6. 核心功能需求
### 6.1 引导流程（Onboarding）
- 3 步结构：
- 第一步选择主要场景（助眠/专注/放松）。
- 第二步演示轨道音量调节。
- 第三步强调产品承诺（离线、零打扰、买断）。
- 关键行为：
- 支持“跳过”和“继续/开始使用”。
- 完成后进入主页。

### 6.2 声音库与分类
- 分类：自然、城市、噪音、频率（原型已定义）。
- 关键交互：
- 单击声音图标用于快速预览（原型注释目标）。
- 双击声音图标添加到混音轨道（原型已实现）。
- 状态反馈：
- 已添加到轨道的声音在图标上有激活态。

### 6.3 混音轨道
- 默认初始轨道 3 条（雨声、远处雷声、篝火）。
- 每条轨道可独立调节音量（0-100%）。
- 支持移除轨道。
- 上限 8 条轨道（超限提示）。
- 播放中显示轻量波形动画反馈。

### 6.4 播放控制
- 底部中央主按钮负责播放/暂停切换。
- 暂停时停止动态视觉反馈，恢复播放时继续。

### 6.5 预设系统
- 入口：主页底部“预设”按钮。
- 预设分组：
- 官方预设（助眠/专注/放松）。
- 我的预设。
- 功能能力：
- 点击预设后更新当前预设标签并应用。
- 支持“保存当前”（MVP 可先做占位，后续实现持久化）。

### 6.6 定时关闭
- 入口：主页底部“定时”按钮。
- 预置时长：15/30/45/60/90 分钟 + 自定义入口。
- 支持“开始计时”和“清除”。
- 状态反馈：
- 主页显示剩余时间 Badge。
- 定时按钮显示当前分钟值（如 `45 min`）。
- 包含“最后 5 分钟淡出”的交互入口（MVP 可先固定规则）。

### 6.7 随机音景
- 入口：主页右上角随机按钮。
- 行为：从全量声音中随机 2-4 条生成临时混音，并随机音量。
- 结果：当前预设文案更新为“随机音景”。

### 6.8 设置页
- 音频：输出设备、与其他 App 混音开关。
- 外观：主题（当前深色）。
- 数据：导出 JSON、导入、匿名数据采集开关。
- 商业与关于：升级完整版（¥38）、扩展包入口、隐私政策、版本号。

## 7. 关键用户流程
### 7.1 助眠主流程
1. 首次打开完成/跳过引导。
2. 在主页直接播放默认音景或选择“助眠预设”。
3. 设置 45 分钟定时并开始。
4. 熄屏入睡（音频后台继续）。

### 7.2 专注主流程
1. 切换至“城市/噪音”分类。
2. 双击添加 1-3 个声音并微调音量。
3. 保存为“我的预设”（V1.1 完整实现）。

## 8. 商业化与版本策略
- 免费层：基础音景 + 播放 + 定时 + 基础设置。
- 付费层：
- 一次买断解锁完整版（价格锚点 ¥38）。
- 扩展音景包（按包解锁）。
- 订阅不作为 MVP 必选方案。

## 9. 非功能需求
- 平台：iOS（优先 iPhone 机型，适配 390pt 宽基线并向上兼容）。
- 性能：
- 首屏可交互时间 <= 1.5 秒（本地资源）。
- 播放与调音操作响应 <= 100ms。
- 音频播放稳定，无可感知卡顿/爆音。
- 离线能力：
- 核心功能可离线使用。
- 无网络时不影响播放、定时、预设加载。
- 隐私合规：
- 匿名采集默认关闭或显式告知并可随时关闭。
- 数据导出导入仅处理本地数据。

## 11. MVP 范围边界
### 11.1 本期必须
- 播放/暂停、声音分类、添加轨道、音量调节、删除轨道。
- 预设选择、定时开始/清除、设置页基础项。
- 引导页 3 步流程。

### 11.2 下期（建议 V1.1）
- 自定义时长完整输入。
- “保存当前”与“我的预设”持久化。
- 轨道长按高级参数（声像、淡入淡出、细粒度增益）。
- iCloud 同步与多端数据迁移。

## 12. 验收标准（QA Checklist）
- 用户可在 2 步内开始播放。
- 轨道操作符合上限规则，提示文案正确。
- 定时状态在主页、浮层、播放状态之间一致。
- 切换预设后当前预设名称正确更新。
- 进入后台/锁屏后音频不断播（在系统许可场景下）。
- 无网络情况下可完成核心闭环。

## 13. 风险与待确认项
- 原型包含“频率（脑波）”内容，需法务确认文案避免医疗暗示。
- “一次买断 + 扩展包”的最终支付模型需与 App Store IAP 规则对齐。
- 自定义定时、预设持久化、导入导出的数据结构需要技术方案评审。
